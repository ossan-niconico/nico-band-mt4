# SIN-nico-band（MT4版）

7つの時間足のATRトレンドバンドに、移動平均線と節目の線、今の相場の様子をまとめた表を足したMT4用インジケーターです。無料でお使いいただけます。
ATRトレンドバンドは、ATR（値動きの大きさ）をもとに、相場の向きを帯で示す線です。
作者が前に配っていた「nico-band-7TF」（7TF は7つの時間足の意味）の新しい版で、2026年11月から無料で配布しています。TradingView版（SIN-nico-band）と同じ計算です。
売買のシグナル・通知は入っていません。チャートの環境を見るための道具です。
MT4 用です。MT5 では使えません。

## 入っているもの

- 1分足から日足まで、7つの時間足のバンド（時間足ごとに色を分けています）
- 移動平均線5種類
- ピボットなど、節目になりやすい値段の線
- 初めは表示していない補助の線（設定で表示できます）
- 左下の表：今の相場の様子と、重要指標の予定

作者はドル円の5分足で使っています。ほかの通貨ペアでも表示できます。
重要指標の一覧は、公式の発表予定から2027年12月まで入れています。それより後の分は、新しい版で足す予定です。

## FX 会社のサーバー時間について

日足・週足の区切りと日本時間は、MT4 のサーバー時間が「ニューヨーク時間＋7時間」（冬は GMT+2、夏は GMT+3）だとして計算しています。海外の FX 会社の MT4 の多くがこの時間です。
サーバー時間が違う会社の MT4 では、ピボットなどの節目の線と、重要指標の時刻がずれます。

## 入れ方

1. このページの上にあるファイルの一覧から、`SIN-nico-band.mq4` を押して開きます。右上のダウンロードのボタン（Download raw file）で保存します。
2. MT4 のメニューの「ファイル」→「データフォルダを開く」を選びます。
3. 開いたフォルダの MQL4 → Indicators に、保存したファイルを入れます。
4. MT4 を再起動します。再起動の時に、MT4 がファイルを使える形に変えます（コンパイル）。
5. ナビゲーターの「インディケータ」にある「SIN-nico-band」を、チャートにドラッグします。

ナビゲーターに出ない時は、`SIN-nico-band.mq4` を MetaEditor で開き、F7 を押してください（コンパイル）。
新しい版が出た時は、Indicators の中のファイルを新しいファイルに置き換えて、MT4 を再起動します。

## 入れた直後に出るもの

入れた直後は、いくつかの時間足のバンドと、移動平均線・節目の線・左下の表が出ます。
ほかの時間足のバンドは、チャートを右クリック →「表示中のインディケータ」→「編集」の「パラメーターの入力」で、それぞれの「表示」を true（表示する）に変えると出ます。
時間足の大きいチャートでは、短い時間足の線は出ません。TradingView版とは、線が出るチャートの時間足が少し違います。

上の時間足のバンドと線は、今開いているチャートの過去の足から計算します。そのため、チャートの過去の足が足りないと出ません。
5分足のチャートなら、過去の足が5週間分ほどあると、全部の線が出ます。足りない時は、チャートを左へ動かして過去の足を読み込みます。
